DevLauncher b1.1 更新日志（2026-10-01）

【多账号管理】
- 账户页改为账号卡片列表：离线账号与 Microsoft 账号并存，点击头像一键切换
- 切号/删除不再跳页、不再弹欢迎提示；删除有二次确认，删除当前账号自动回退最近账号
- 登出 = 取消选中：账号保留在列表可随时切回；重启后账号、当前选择与排序保持
- 旧版 auth.json 自动迁移为首个账号（原文件保留）
- 登录令牌仅保存在本机 %USERPROFILE%\.mc-launcher\accounts.json，界面永不显示

【插件系统】
- 侧栏新增第 8 个"插件"页签：把插件文件夹放进 exe 旁的 plugins/ 即可识别
- 内置示例插件 hello-sample，开箱即用
- 一键启用/禁用/重新加载/卸载（卸载有二次确认并自动返回列表）
- 设置面板：文本/开关/数字三类表单，保存即生效无需重启
- 详情页：基本信息 + 操作按钮 + 插件自定义内容区 + 一键打开插件文件夹
- 安全防护：插件目录路径穿越防护、界面输出转义防注入

【本版打包】
- 新增 Windows 单文件版 DevLauncher.exe，双击即用，免安装 Python
- 自定义程序图标与文件版本信息（右键属性 → 详细信息可见 1.1.0.0）
- 日志与插件目录跟随 exe 所在目录，绿色便携可放任意位置
- 105+ 项 Python 自动化测试与界面断言全绿

【首次运行提示】
- 从网络下载的未签名程序会触发 Windows SmartScreen："更多信息 → 仍要运行"即可
- 或右键 DevLauncher.exe → 属性 → 勾选"解除锁定" → 确定，之后不再提示
- 本程序未做代码签名（需购买证书），SmartScreen 提示属正常现象

【升级方法】
- 解压后双击 DevLauncher.exe；已有账号与设置存于 C:\Users\<你>\.mc-launcher，自动沿用
- 无需卸载旧版，直接运行即可
