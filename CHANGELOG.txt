DevLauncher 1.2.0 更新日志（2026-10-11，2026-10-18 补充）

【下载进度条修复】
- 修复进度面板出现但进度条永远停在 0%（脚本引用了不存在的界面元素导致报错中断）
- 进度按百分比推进并显示在计数位；版本安装接住分段进度（库/资源两段拼成整体，单调不回跳，封顶 99%）
- 进度文案改安全注入，文件名含引号也不会打断脚本

【LiquidBounce 网页下载完善】
- 打开下载页时后台解析官方构建接口，永远直达最新 release 的下载页
- 官网直链产物实为 zip（内含 liquidbounce.jar）：.jar/.zip 一律接管，下载后解包取 jar 进实例，zip 不残留
- 注入探针让官网按官方 LiquidLauncher 观感隐藏导航/页脚；关闭窗口不再报 Qt 释放顺序错误

【客户端目录】
- 分类改为多标签（作弊/PVP/生存），一条目可多标签，卡片徽章与搜索按标签匹配
- 宽 logo 图标不再被方框裁切
- LiquidBounce 直达手动下载锚点

【启动与网络】
- 版本列表磁盘缓存：冷启动先渲染缓存再联网刷新，断网也能用
- 双击启动（无环境变量）时读 Windows 系统代理，内置网页在代理环境下不再直连超时

【修复】
- mods 列表不再把去重清理目录当成模组目录（幽灵条目）
- 全套回归：pytest 196 项 + 界面断言 821 项 0 失败

【界面中英双语】
- 界面文案支持中英切换：「设置 → 界面语言」即时生效并持久化；按文本节点匹配，无需改动界面标记

【图形化游戏设置】
- 新增图形化游戏设置，直接编辑 options.txt（渲染距离 / 视野 / 音量等），无需手改文件

【工具插件 ×3】
- 内置插件新增 instance-size（实例体积统计）、java-doctor（Java 环境体检）、mods-doctor（模组排查）

【整合包与网络】
- 支持导出实例为 .mrpack；解析模组依赖与可选依赖，缺失依赖时给出提示
- 下载提速：网络层统一重试与进度上报

【账户页签与皮肤披风】
- 账户管理整合皮肤与披风并独立成页签；「当前皮肤 / 披风 / 说明」改为卡片上方的暗灰小标题，不再一字一行竖排
- 披风卡片新增预览图：自动显示当前穿戴的披风，装备 / 隐藏后即时刷新
- 更换皮肤的下拉框统一为深色主题控件，文字清晰可见
- 微软登录图标改用官方四色品牌 Logo

【启动与打包修复】
- 修复打包后启动崩溃：导入的 `fast_install` 是函数而非模块，模块属性访问报错
- 冒烟判据加固：除「进程存活」外还要求日志出现启动完成标记，避免「异常对话框挂着」被误判为构建成功
- 发布 zip 改为打包全部插件目录
- 微软令牌过期或服务端返回 401 时自动刷新并只重试一次，仍失败时提示「登录已过期，请重新登录」
- 全套回归：pytest 385 项 + 界面断言 1040 项 0 失败

DevLauncher 1.1.5 更新日志（2026-10-08）

【客户端实例化安装】
- jar 客户端点「下载」先弹版本选择器（带实例名输入框，默认=客户端名）
- 选中后自动下载 MC 版本 + 加载器 + jar，全部装进新建隔离实例，可直接在版本页启动
- MC 版本回退链：条目标注 → 当前选中（仅严格 MC id 形状）→ Mojang 最新正式版；加载器空默认 Fabric
- 导入进度走 HMCL 风格弹窗（跳确认页、取消锁「导入中...」），完成 2s 自动关窗并选中新实例
- 卡片按钮不永久锁死，可重复下载；导入进行中其它下载被并发锁拦截
- 同模组旧 jar 自动清理（修复重复下载 Meteor 后 mods 目录出现两个 meteor jar）

【导入弹窗收起】
- 导入进行中点「—」整窗收起，进度合并到侧边栏启动按钮上方小面板（标题/计数/进度条/文件列表实时同步）
- 面板 header 可展开还原；完成时自动展开并回收面板；关闭不再重弹

【LiquidBounce 内置网页下载】
- 客户端目录新增第 20 条 LiquidBounce（web_download 策略）：点「下载」在启动器内开网页选版本
- 网页内 .jar 下载被拦截并接管，复用实例安装管线；非 jar 下载一律取消；不调外部浏览器
- QtWebEngine 注入环境代理 --proxy-server（系统代理下应用内网页可直连）

【其他】
- 客户端目录 20 条（14 客户端 + 6 PVP 整合包），19 张卡片图标全部本地化入库（离线可用）
- 图标加载成功后字母兜底与灰底立即隐藏；图标自愈（破图回退字母）
- 下载页模组四段筛选面板（类别/加载器/环境/版本）、版本卡加载器 logo
- 内存优化：QtWebEngine 三 GPU flags（提交内存 275MB → 210MB）

DevLauncher b1.1 更新日志（2026-10-01）

【多账号管理】
- 账户页改为账号卡片列表：离线账号与 Microsoft 账号并存，点击头像一键切换
- 切号/删除不再跳页、不再弹欢迎提示；删除有二次确认，删除当前账号自动回退最近账号
- 登出 = 取消选中：账号保留在列表可随时切回；重启后账号、当前选择与排序保持
- 旧版 auth.json 自动迁移为首个账号（原文件保留）
- 登录令牌仅保存在本机 %USERPROFILE%\.mc-launcher\accounts.json，界面永不显示

【插件系统】
- 侧栏新增第 8 个"插件"页签：把插件文件夹放进 exe 旁的 plugins/ 即可识别
- 内置示例插件 hello-sample，开箱即用
- 一键启用/禁用/重新加载/卸载（卸载有二次确认并自动返回列表）
- 设置面板：文本/开关/数字三类表单，保存即生效无需重启
- 详情页：基本信息 + 操作按钮 + 插件自定义内容区 + 一键打开插件文件夹
- 安全防护：插件目录路径穿越防护、界面输出转义防注入

【本版打包】
- 新增 Windows 单文件版 DevLauncher.exe，双击即用，免安装 Python
- 自定义程序图标与文件版本信息（右键属性 → 详细信息可见 1.1.0.0）
- 日志与插件目录跟随 exe 所在目录，绿色便携可放任意位置
- 105+ 项 Python 自动化测试与界面断言全绿

【首次运行提示】
- 从网络下载的未签名程序会触发 Windows SmartScreen："更多信息 → 仍要运行"即可
- 或右键 DevLauncher.exe → 属性 → 勾选"解除锁定" → 确定，之后不再提示
- 本程序未做代码签名（需购买证书），SmartScreen 提示属正常现象

【升级方法】
- 解压后双击 DevLauncher.exe；已有账号与设置存于 C:\Users\<你>\.mc-launcher，自动沿用
- 无需卸载旧版，直接运行即可
